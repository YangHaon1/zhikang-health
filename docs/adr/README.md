# 架构决策记录（ADR）

记录**为什么这么设计**，而不是怎么用。每条 ADR 都必须写出：

- 当时的备选方案与**被否理由**（只写"我们选了 X"没有信息量）；
- 这个决策的**代价**与已知不利事实（不许只写好处）。

| 编号                                  | 决策                                          | 一句话理由                                                |
| ------------------------------------- | --------------------------------------------- | --------------------------------------------------------- |
| [0001](0001-ml-model-choice.md)       | 风险预测用 LightGBM，LLM 只做表达             | 判定要可解释、可复现、可做分布监控，这三件事 LLM 都做不到 |
| [0002](0002-rule-engine-vs-llm.md)    | 规则引擎与 LLM 解耦，安全结论只来自确定性代码 | 急症分流文案不允许生成式改写；降级必须留痕                |
| [0003](0003-privacy-authorization.md) | 隐私授权独立建表 + 小样本强制隐藏             | 匿名不等于脱敏，样本量阈值必须前后端同源                  |
| [0004](0004-feature-single-source.md) | 特征定义单一来源（`feature-spec.json`）       | 四处各写一份已经真实漂移过两次                            |

## 模板

```markdown
# ADR-XXXX：<决策一句话>

- 状态：已采纳 / 已废弃（被 ADR-YYYY 取代）
- 日期：YYYY-MM-DD
- 相关代码：<路径>

## 背景

## 决策

## 理由

## 已知代价（必须如实交代）

## 被否方案

## 影响
```
