# 亚健康风险预测模型说明

## 模型目标

根据大学生的生活方式数据，预测**生活方式型亚健康风险倾向**（低 / 中 / 高），并给出 Top 影响因素。

> ⚠️ 本模型输出是**生活方式风险提示**，不是疾病诊断，不能替代专业医疗评估。

## 数据来源与训练模式

- **真实来源**：`health_survey` 大学生健康调研表（睡眠/压力/运动/饮食/生活方式 12 项）
- **特征**：15 维生活方式行为特征（`server-ml/dataset.py` 负责问卷 → 特征向量映射）
- **标签**：`survey-label` 规则打分产出 low / medium / high（生活方式风险，非诊断）
- **当前模型版本**：`lgbm-v0.3`
- **当前训练模式**：`synthetic_only`
  - 真实样本数：**0**（问卷刚上线，正在积累）
  - 合成样本数：**4000**

### 训练模式（三档，自动切换）

| 模式            | 触发条件       | 含义                    |
| --------------- | -------------- | ----------------------- |
| synthetic_only  | 真实样本 <20   | 纯合成数据训练（当前）  |
| hybrid_training | 真实样本 20~99 | 真实问卷 + 合成合并训练 |
| real_priority   | 真实样本 ≥100  | 真实为主、合成兜底      |

### 训练数据流

```
health_survey（大学生调研）
        ↓
dataset.py（问卷 → 15 维特征）
        ↓
feature vector
        ↓
LightGBM（lgbm）
        ↓
risk_level + risk_probability
        ↓
SHAP explanation（Top 影响因素）
```

## 模型实验结果

| 项       | 结果                                                            |
| -------- | --------------------------------------------------------------- |
| 模型名称 | LightGBM 多分类                                                 |
| 版本     | lgbm-v0.3                                                       |
| 任务     | 生活方式型亚健康风险分类（low/medium/high）                     |
| 输入     | 15 维行为特征                                                   |
| 训练模式 | synthetic_only                                                  |
| 数据规模 | 合成 4000 条（80% train / 20% test，stratify，random_state=42） |

| 指标         | 结果  |
| ------------ | ----- |
| Accuracy     | 0.981 |
| Macro-F1     | 0.972 |
| ROC-AUC(OVR) | 0.999 |

分类别：

| 类别   | Precision | Recall | F1    |
| ------ | --------- | ------ | ----- |
| low    | 1.000     | 0.909  | 0.952 |
| medium | 0.981     | 0.987  | 0.984 |
| high   | 0.979     | 0.982  | 0.980 |

混淆矩阵（真实\预测，low/med/high）：

```
[[ 40,   4,   0],
 [  0, 471,   6],
 [  0,   5, 274]]
```

## 输入特征（15 维）

睡眠时长/睡眠不足天数/睡眠质量、运动时长/天数、压力均值/高压天数、饮食规律占比、情绪、学习时长、久坐、就寝时间、BMI、年级/是否走读。

## 输出

```json
{ "riskLevel": "low|medium|high", "riskProbability": 0~1,
  "dataQuality": {"level","filledRatio"},
  "shapFactors": [{"label","direction"}],
  "modelVersion": "lgbm-v0.3" }
```

## ⚠️ 限制

- 本模型仅用于**生活方式风险倾向分析**，**不用于疾病预测或医学诊断**；
- 当前阶段为 `synthetic_only`，真实问卷样本仍在积累，指标高源于标签由规则定义，不代表真实临床效果；
- 后续随真实问卷样本增长，自动切换 hybrid / real_priority 并持续重训优化；
- 输出建议仅供健康管理参考。
